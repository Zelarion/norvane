# Norvane Cold Systems (concept project)

A fictional commercial-refrigeration company, built by Zelarion as a concept website. All names, contacts, clients, partners and figures are illustrative.

## Stack

- Next.js (App Router, TypeScript), Tailwind CSS v4, shadcn/ui
- framer-motion for scroll reveals, React Three Fiber for the 3D hero

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm start
```

## Pages

`/` · `/about` · `/industries` (+ `/industries/[sector]`) · `/products` · `/contact`

The site is set to `noindex` and `robots.txt` disallows all crawling, so it stays out of search results.
